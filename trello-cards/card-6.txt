As a manager, I want to view applicants so that I can evaluate them



When Filter Option and Search Keyword are invalid, the system must show no results.

When Filter Option is invalid but Search Keyword is valid, the system must show unfiltered results.

When Filter Option is valid but Search Keyword is invalid, the system must show filtered results.

When both are valid, the system must show filtered and searched results.
